A3PF - Automatic Acoustic Analysis of Polish Fricatives
by Till Preidt and Dr. Jacek Kudera

This repository is a branch of the original research repository. It provides a streamlined, publication-oriented version containing the scripts, documentation, and results relevant to the accompanying paper. Therefore path configurations within the scripts might be derivating.

The full research project includes additional processing materials and intermediate outputs that are not required to reproduce or understand the analyses reported here. Due to their substantial storage requirements, the source audio recordings and models joblib files are not included in this repository.

Please have a look a the LICENSE before using this repository.
